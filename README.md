# SECE Centralized Procurement Hub

Split from the single-file build into separate source files.

```
index.html          – page markup (login, dashboards, modals)
css/tailwind.css    – compiled Tailwind CSS v4 (generated, don't hand-edit)
css/style.css       – custom styles (scrollbar, toast animation, print layout)
js/app.js           – all app logic (data, workflow, rendering, events)
assets/             – favicon, college logo, emblem
```

Run: open `index.html` in a browser (or `npx serve .`).
